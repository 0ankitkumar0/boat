# Boat Listing

A simple bookable boats and yachts listing page built using React 17 as part of a frontend development internship task.

## Features

* Boat and yacht listing
* Search by boat name or location
* Filter by boat type
* Filter by availability
* Loading state
* Empty state
* Responsive boat cards
* Reusable React components

## Tech Stack

* React 17
* Create React App
* JavaScript ES6+
* CSS

## Setup

Clone the repository:

```bash
git clone https://github.com/0ankitkumar0/boat.git
```

Go to the project folder:

```bash
cd boat
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm start
```

The application will run at:

```text
http://localhost:3000
```
